# Angelo Angelidis Portfolio

Personal portfolio site focused on technical support, IT operations, customer support, and troubleshooting.

## About

This site brings together my customer service background, technical skills, Computer Science coursework, and support-focused projects.

## Projects Featured

### Support Ticket Dashboard
An AI-assisted browser-based support ticket dashboard used to explore common support workflows such as ticket creation, prioritization, status tracking, searching, filtering, and resolution.

### Technical Support Troubleshooting Knowledge Base
An AI-assisted technical documentation project focused on practical Tier 1 troubleshooting, verification, documentation, and escalation.
